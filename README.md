# xyodfish.github.io

Personal site for **xyodfish** — robotics software / motion-control engineer.

- Chinese: `/`
- English: `/en/`
- Bilingual case studies: `/work/<case>/` and `/en/work/<case>/`
- Responsive editorial layout with viewport-aware demo playback

## Local

```bash
npm install
npm run dev
```

## Deploy

Push to `main`. GitHub Actions builds Astro and deploys to GitHub Pages.

In the repo settings, set Pages source to **GitHub Actions**.
